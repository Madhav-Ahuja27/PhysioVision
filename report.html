AI Fitness Pose Analyzer

Computer Vision Capstone Project Report

Real-Time Pose Estimation with AI-Powered Form Correction

1. Problem Statement and Motivation

Home fitness has grown exponentially, yet most people exercise without professional supervision. Incorrect form is a leading cause of workout injuries including muscle strains and joint damage. Hiring trainers is expensive and inaccessible. The AI Fitness Pose Analyzer bridges this gap by providing real-time, AI-powered exercise form feedback using only a webcam or static image. It democratizes access to professional-grade form analysis, making safe exercise guidance available to anyone with a camera.

2. Model and Approach

2.1 Pose Estimation: MediaPipe Pose

We use Google's pretrained MediaPipe Pose model, which detects 33 3D body landmarks in real time via a BlazePose detector-tracker pipeline. It was selected because it runs efficiently on CPU, provides visibility scores for occlusion handling, and requires no additional training data or GPU.

2.2 AI Feedback: Groq LLM (Llama 3.3 70B)

For intelligent form analysis, we use the Groq API with Meta's Llama 3.3 70B Versatile model. The LLM receives structured angle data and generates physiotherapist-style corrective feedback. This produces natural, contextual guidance rather than rigid template responses, without requiring any labeled training dataset.

3. Dataset and Test Data

MediaPipe Pose is fully pretrained on Google's internal dataset, so no custom dataset collection or model training was required. For validation, we use sample exercise images (squats, lunges, stretches) to verify landmark detection accuracy, angle calculation correctness, and LLM feedback relevance. The system also supports direct webcam input for live real-world validation.

5. System Pipeline

The pipeline has five stages:

INPUT
Static image or live webcam frame (BGR, any resolution)
↓
STEP 1
MediaPipe Pose processes RGB frame; outputs 33 landmarks with visibility scores
↓
STEP 2
NumPy computes joint angles using 2D arctan2 vector geometry on key triplets
↓
STEP 3
Angle dictionary formatted into physiotherapist prompt; sent to Groq LLM
↓
OUTPUT
Annotated image with skeletal overlay, angle labels, and AI feedback panel

The system operates in two modes: static mode (inference.py) analyzes a single image end-to-end; webcam mode (inference_webcam.py) runs MediaPipe at camera framerate while LLM feedback updates every 5 seconds via a background thread.
